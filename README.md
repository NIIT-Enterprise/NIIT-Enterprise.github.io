# NIIT Enterprise Programs

Program design pages, published with GitHub Pages.

| Folder | Program |
|---|---|
| `Engineering-Manager/` | Engineering Manager Program in the AI Era |

## Adding a program

1. Create a folder (for example `FDE/`) and put the program page inside it as `index.html`.
2. In the root `index.html`, copy the existing card, point its link at the new folder (`FDE/`) and update the text.
3. Commit. The site refreshes within a minute or two.

Pages carry a `noindex` tag so search engines skip them; they are still open to anyone with the link.
